# Data Science

This course focused on applying statistical programming and data science methods to large, real-world datasets, with an emphasis on reproducible analysis, interactive applications, and effective communication of results.

## Key Skills and Learning Outcomes

* Developed statistical programming solutions using R, the Tidyverse, and R Markdown/Quarto to conduct efficient, reproducible analyses of large and complex datasets.

* Applied web scraping and APIs to efficiently and securely acquire data from online sources.

* Used code-based approaches to clean, transform, manage, and analyze large datasets.

* Applied SQL for querying, manipulating, and analyzing structured data.

* Developed interactive web-based applications, dashboards, and data products to support data exploration, visualization, and communication of analytical results.

* Built interactive tools that allow users to develop explanatory and predictive models, test hypotheses, evaluate model assumptions, and interpret statistical results.

* Evaluated data science applications from an ethical perspective, identifying potential ethical concerns and appropriate mitigation strategies.

* Explored approaches for engaging with and contributing to the professional Data Science community.

## Technologies and Tools

R | Tidyverse | R Markdown/Quarto | Shiny | SQL | APIs | Web Scraping | Data Visualization | Statistical Modeling | Interactive Dashboards
